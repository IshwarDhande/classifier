# MP05 — VP ↔ I Minimal-Pair Variants

## Boundary

**VP — Very Positive** ↔ **I — Indifferent**

## Diagnostic Distinction

- **VP:** The user shows strong acceptance, enthusiasm, appreciation, or proactive engagement with the intervention.
- **I:** The user acknowledges, considers, or responds to the intervention without sufficient evidence of acceptance, rejection, or behavioral commitment.

The contrast is grounded in behavioral engagement. Positive wording, politeness, or acknowledgement alone must not determine VP.

## Construction Rule

Each pair preserves:
- the same task domain;
- the same underlying intervention/action;
- the same conversational situation;
- comparable information and specificity.

The primary contrast is whether the user demonstrates **strong positive engagement (VP)** or merely **acknowledges/considers without behavioral commitment (I)**.

Only user responses are represented. The preceding task-reminder intervention is implicit.
