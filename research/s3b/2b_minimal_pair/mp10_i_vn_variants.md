# MP10 — I ↔ VN Minimal-Pair Variants

## Boundary

**I — Indifferent** ↔ **VN — Very Negative**

## Diagnostic Distinction

- **I:** The user acknowledges, considers, or responds to the intervention without sufficient behavioral evidence of either acceptance or rejection.
- **VN:** The user demonstrates strong rejection, explicit opposition, high reactance, hostility, or active disengagement from the intervention or interaction.

The contrast is based on behavioral evidence. A neutral acknowledgement must not be treated as rejection, and strong resistance must not be reduced to mere uncertainty.

## Construction Rule

Each pair preserves:
- the same task domain;
- the same underlying intervention/action;
- the same conversational situation;
- comparable information and specificity.

The primary contrast is:
- I = the user leaves the behavioral decision open without clear acceptance or resistance.
- VN = the user strongly rejects the intervention or disengages from the interaction.

Only user responses are represented. The preceding task-reminder intervention is implicit.
