# MP02 — P ↔ I Minimal-Pair Variants

## Boundary

**P — Positive** ↔ **I — Indifferent**

## Diagnostic Distinction

- **P:** The user demonstrates genuine acceptance, cooperation, or behavioral commitment toward the intervention.
- **I:** The user acknowledges, considers, or responds to the intervention without sufficient evidence of acceptance, rejection, or behavioral commitment.

The contrast is based on behavioral evidence rather than sentiment, politeness, or isolated lexical cues.

## Construction Rule

Each pair preserves:
- the same task domain;
- the same underlying behavioral option;
- the same conversational situation;
- comparable informational content;
- the same implied task intervention.

The primary contrast is whether the user **commits to the behavior (P)** or merely **leaves the option open without behavioral commitment (I)**.

Only user responses are represented. The preceding task-reminder intervention is implicit.
