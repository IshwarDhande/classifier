# MP07 — VP ↔ VN Minimal-Pair Variants

## Boundary

**VP — Very Positive** ↔ **VN — Very Negative**

## Diagnostic Distinction

- **VP:** The user demonstrates strong acceptance, enthusiasm, appreciation, and proactive cooperation toward the intervention.
- **VN:** The user demonstrates strong rejection, explicit opposition, high reactance, hostility, or active disengagement from the intervention or interaction.

The contrast is established through behavioral response and interactional stance, not merely positive or negative sentiment.

## Construction Rule

Each pair preserves:
- the same task domain;
- the same underlying intervention/action;
- the same conversational situation;
- comparable information and specificity.

The primary contrast is the user's **behavioral engagement versus strong rejection/reactance**:
- VP = strong voluntary cooperation, enthusiasm, appreciation, or proactive engagement.
- VN = strong opposition, explicit rejection, reactance, hostility, or active disengagement.

Only user responses are represented. The preceding task-reminder intervention is implicit.
