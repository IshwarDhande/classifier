# MP06 — VP ↔ N Minimal-Pair Variants

## Boundary

**VP — Very Positive** ↔ **N — Negative**

## Diagnostic Distinction

- **VP:** The user demonstrates strong acceptance, enthusiasm, appreciation, or proactive cooperation toward the intervention.
- **N:** The user demonstrates reluctance, disagreement, mild refusal, or conditional resistance, without strong rejection, hostility, or active disengagement.

The contrast is based on behavioral orientation toward the intervention, not emotional tone or isolated lexical cues.

## Construction Rule

Each pair preserves:
- the same task domain;
- the same underlying intervention/action;
- the same conversational situation;
- comparable information and specificity.

The primary contrast is the user's behavioral orientation:
- VP = strong positive engagement or proactive cooperation.
- N = recoverable reluctance or resistance.

Only user responses are represented. The preceding task-reminder intervention is implicit.
