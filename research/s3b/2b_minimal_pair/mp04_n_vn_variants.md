# MP04 — N ↔ VN Minimal-Pair Variants

## Boundary

**N — Negative** ↔ **VN — Very Negative**

## Diagnostic Distinction

- **N:** The user shows reluctance, disagreement, mild refusal, or conditional resistance toward the intervention, but the response remains potentially recoverable.
- **VN:** The user expresses strong rejection, explicit opposition, high reactance, hostility, or active disengagement from the intervention or interaction.

The contrast is based on the strength of behavioral resistance. A negative sentiment or simple refusal is not sufficient by itself for VN.

## Construction Rule

Each pair preserves:
- the same task domain;
- the same underlying intervention/action;
- the same conversational situation;
- comparable information and specificity.

The primary contrast is the **strength and interactional scope of resistance**:
- N remains limited, negotiable, or recoverable.
- VN contains strong opposition, explicit rejection, reactance, or disengagement.

Only user responses are represented. The preceding task-reminder intervention is implicit.
