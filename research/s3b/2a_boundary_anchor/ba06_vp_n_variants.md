# BA06 — VP ↔ N Boundary Variants

## Boundary

**VP — Very Positive** ↔ **N — Negative**

## Construction Rule

These variants expand the six Stage 2A BA06 anchors while preserving:
- the VP↔N boundary;
- the original anchor role;
- strong acceptance/proactive engagement for VP;
- recoverable behavioral resistance for N;
- the implied response to an existing task reminder/intervention;
- natural conversational language without sentiment or refusal-word shortcuts.

Only the user's response is represented. The preceding agent intervention is implicit.
