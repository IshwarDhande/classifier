# BA08 — P ↔ N Boundary Variants

## Boundary

**P — Positive** ↔ **N — Negative**

## Construction Rule

These variants expand the six Stage 2A BA08 anchors while preserving:
- the P↔N boundary;
- the original anchor role;
- ordinary behavioral acceptance/cooperation for P;
- recoverable behavioral resistance for N;
- the implied response to an existing task reminder/intervention;
- natural conversational language without sentiment or keyword shortcuts.

Only the user's response is represented. The preceding agent intervention is implicit.
