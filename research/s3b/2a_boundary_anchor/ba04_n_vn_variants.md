# BA04 — N ↔ VN Boundary Variants

## Boundary

**N — Negative** ↔ **VN — Very Negative**

## Construction Rule

These variants expand the six Stage 2A BA04 anchors while preserving:
- the N↔VN boundary;
- the original anchor role;
- recoverable resistance for N;
- strong rejection, reactance, or active disengagement for VN;
- the implied response to an existing task reminder/intervention;
- natural conversational language without refusal-word shortcuts.

Only the user's response is represented. The preceding agent intervention is implicit.
