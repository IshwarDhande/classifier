# Execution Status File Guide

This guide provides an overview and logical categorization of all the "execution status" related documents. The directory is organized to document the ontology first, followed by practical differentiation guidelines.

## 1. Formal Definitions & Architecture

* `01_execution_status_ontology.md`: Specifies the formal Execution Status Ontology (ESO). It defines the three execution states (Not Started, In Progress, Completed), their boundary cases, and how they relate to the broader conversational architecture.

## 2. Annotation & Practical Guidelines

* `02_execution_status_differentiation_guide.md`: A practical guide designed to help annotators and system designers correctly distinguish between execution status states. Provides a decision tree, examples, and rules for avoiding common annotation mistakes.
