# 5. Interpretation

### Working

`Working` is a strong direct signal of ongoing execution.

### Doing

`Doing` is also a strong direct signal when the expression indicates that the action is currently being performed.

### Trying

`Trying` requires additional caution. A person can be trying to begin an action without having actually begun execution. Therefore, `Trying` variants should receive additional semantic review before being included in the final SRCC.

For example:

```text
"I'm working on it."       → IP
"I'm doing it."            → IP
"I'm trying to finish it." → IP
```

The third expression requires more semantic interpretation than the first two.
