# Models Directory

Saved model checkpoints and weights (`model.safetensors`, `config.json`, tokenizer files) will be saved in subdirectories organized by task and dataset variant:

- `execution_status/dataset_2/best_model/`
- `execution_status/combined/best_model/`
- `response_category/dataset_2/best_model/`
- `response_category/combined/best_model/`
